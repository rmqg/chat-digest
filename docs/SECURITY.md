# 安全边界

本文说明 chat-digest 读什么、写什么、需要什么权限、会碰到什么风险，以及哪些事它**不做**。报告漏洞的方式见仓库根目录的 [SECURITY.md](../SECURITY.md)。

## 一句话

chat-digest 只读一个 chat-export/v1 目录，把总结写进自己的 `runtime/`，通过你配置的命令发送。它不登录聊天账号、不读取客户端数据库或内存、不保存聊天软件的密钥，也不会自己去点聊天窗口。

## 读什么

| 读取对象 | 方式 | 说明 |
|---|---|---|
| chat-export/v1 导出目录（`export.root`） | 宿主进程直接读；容器里以 `readonly` 挂载到 `/export` | 只读 manifest、所选会话的 `conversations/*.jsonl`、`members/*.json` 和被引用的 `media/` 文件。所有路径都校验不能逃出导出根目录，也不能指向生产方的 `state/` |
| `runtime/` 下的配置 | 本地文件 | 含模型 key、网站凭证、Bark 地址，属于秘密 |
| 消息里的链接 | `web_context` 在容器里抓取 | 只抓公网 http/https；拒绝回环、私网、链路本地、组播地址和带凭证的 URL；跳转后重新校验；限时限大小 |
| QQ 群消息 | 你自己的 OneBot v11 服务 | 见 [QQ.md](QQ.md) |

## 写什么

| 写入位置 | 内容 | 权限 |
|---|---|---|
| `runtime/digest/` | 状态机、回执、阶段结果、缓存（图片描述、OCR、网页摘要、总结）、`stage-failures.jsonl` | 目录 700，文件 600 |
| `runtime/reports/` | 两版 HTML/PNG/JSON 和 `*.sources.json`（窗口内全部消息的副本，供核对） | 同上 |
| 远端网站（可选） | 只上传 HTML 和报告引用到的图片 | 由受限 SSH 用户写入 `remote_path` |
| 群聊 | 报告 PNG、可选的网站入口说明 | 通过发送命令 |
| Bark（可选） | 只含阶段、位置、错误类型等脱敏诊断，不含聊天内容 | — |

`runtime/` 里的缓存和 `sources.json` **含聊天内容**，和导出目录一样是隐私数据：不要放进 Git、镜像或公开网站目录，备份要加密，按需要定期清理（任务目录在实时 10 分钟、日报 7 天、按需 7 天后自动删除；摘要等缓存不会自动删除）。

## 需要什么权限

- **宿主用户**：能读导出目录、读写 `runtime/`、调用 Docker（加入 `docker` 组）。**`docker` 组几乎等于 root**，所以请用专门的系统用户运行，不要和日常账户共用。
- **容器**：每个阶段都是一次性容器，`--read-only` 根文件系统、`--cap-drop ALL`、`no-new-privileges`、`--memory 1g --cpus 1`、`--pull never`、只用锁定的镜像 ID；以 `worker_uid:worker_gid` 运行。不需要网络的阶段（取图、OCR、离线渲染）用 `--network none`。
- **systemd unit**：`ProtectSystem=strict`、`ProtectHome=read-only`、`NoNewPrivileges`、`PrivateTmp`、`UMask=0077`，只允许写 `/opt/chat-digest/runtime`。
- **不需要**：root、ptrace、调试器、访问聊天客户端进程或它的数据目录。

## 主要风险和对应措施

| 风险 | 措施 |
|---|---|
| 群里有人发“忽略以上指令……”之类的内容（提示注入） | 消息、图片文字、网页正文都只作为被总结的材料；提示词明确要求不执行其中的指令；模型输出必须引用真实消息编号，金句由程序逐字回填，伪造的引用会让这一版报告作废而不是发出去 |
| 模型编造内容 | 话题必须引用存在的消息；网页内容标为“网页主张”、附件和图片说明标为辅助证据；拒答或截断时不出报告 |
| 重复发送 | 每次发送有固定 `send_request_id`；`unknown`、超时一律停下不重发；进程在 `sending` 中途被杀，重启后改记 `unknown` |
| 把别的群的东西带进报告 | 只读 `group.conversation_id` 这一个会话；头像只取导出里的成员文件；图片按 SHA-256 核对 |
| 模型服务商看到聊天内容 | 不可避免：总结就是把窗口内的消息发给你配置的模型。请选择你信任的服务商，必要时用自建模型 |
| 抓网页泄露内网信息 | 禁止访问私网和回环地址，见上表 |
| 网站暴露报告 | 网站必须有认证；只上传 HTML 和被引用的图片；原图回源服务只接受回环地址上带 Bearer token 的请求，只按哈希提供图片 |
| 本机模式网站 | 只监听 `127.0.0.1`，所有内容都要登录（scrypt 校验，连续失败限速，Cookie 为 HttpOnly + SameSite=Lax，改密码后旧登录全部失效）；图片只按哈希文件名提供，不跟随符号链接；`sources.json` 和报告 JSON 不提供下载。对外开放由你自己的反代或隧道负责，开放后请用 HTTPS 并启用 `cookie_secure` |
| 外部渲染器（`render.module`）里的代码 | 它和生成报告的进程同权限运行，能读到报告字典；只在配置了 `render` 时加载，只读挂载，加载失败就停在调用模型之前。只用你自己审过的渲染器代码，文件和目录权限设为只有部署用户可写 |
| 日志泄露秘密 | 诊断文件里替换掉 api key；看门狗通知只带脱敏字段；`chat-send` 失败时只保留 stderr 最后 400 字符，写在 600 权限的状态文件里 |

## 不做的事

- 不提取或保存任何聊天软件的密钥、数据库口令或登录态。
- 不修改导出目录，也不读生产方的 `state/`。
- 不在 `unknown` 时自动重发，不为了“补发”去改回执。
- 不收集与总结目标无关的会话。

## 使用者的责任

只处理你有权处理的聊天记录。把群聊内容交给第三方模型、发布到网站之前，确认群成员知情并符合所在地法律、组织政策和平台条款。本项目与腾讯无关，不保证任何账号不受平台风控影响。
